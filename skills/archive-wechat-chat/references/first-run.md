# 首次使用与验收

## 普通用户

本流程适用于 Codex 与 Claude Code。下文 Codex 模型名只用于 Codex；Claude Code 按 [宿主适配](claude-code.md) 保持当前主聊天模型编排，先询问用户思考/复核与执行/转录各用哪些模型。当前主聊天就是编排者，不能用另一个“编排子代理”代替它。验证报告必须区分宿主；一种客户端成功不证明另一种客户端的桌面工具已可用。

用户只需在已安装技能的客户端中指定聊天、想保存的范围和本地输出目录。若目标微信窗口已经打开，主代理先观察进入路径与当前画面，判断这是主聊天、历史搜索结果还是独立合并转发；能判断时不重复询问来源，只有用户范围仍不清楚才简短确认。新手不必自己准备 JSON 或学习 agent；这些由主代理在捕获后生成。模式差异见 [窗口模式与观测](window-modes.md)。

最低运行环境：macOS、已登录微信、Node.js 20 或更新版本；OCR 还需要 Apple Command Line Tools，Swift 工具链不匹配时可用 Clang 后备路径。桌面控制能力由用户的客户端提供，不随此技能安装。终端检查不能证明屏幕录制或辅助功能权限已可用，须进行一次实际 UI 读取。

若 doctor 报缺失：给出具体缺项和操作路径。安装 Node 或运行 `xcode-select --install` 需遵循宿主权限流程，不自动使用 sudo。桌面权限在 macOS 系统设置的“隐私与安全性”中配置；权限名与宿主版本可能不同。没有桌面能力时仍能处理用户提供的捕获材料，但不要称自动微信抓取可用。

## 第一次真实验收

使用 Sol（建议 high）或 Astra（建议 medium），从用户实际使用的一种模式选择短范围，包含正常文字、同内容重复消息和引用；若该范围自然包含图片，一并核对其当前模式实际提供的媒体能力。不要为满足清单而假定或切换到未观察的图片路径。一次真实验收只证明实际观察过的模式；不要把一个模式的滚动或保存行为推广到另一个。本包已对一份 22 条记录的合并转发完成逐页采集、图片导出、CLI 落盘校验及重复导入，也对主聊天一个 3 条可见消息范围完成落盘和重复导入；这不证明完整主聊天历史可用。历史搜索只检查了图片查看与 Save 面板，未完整抓取。验证：

- 用户要求的范围和来源模式一致；起点、终点分别有对应来源内证据。合并转发底部需综合终止线、滚动条位置及稳定画面等本次观察到的证据；条目计数或单次画面不变不单独证明边界，也不证明完整落盘。
- 每条消息作者和正文都能与画面对应；边缘被截断的条目要滚动到作者完整可见再核验。AX/OCR 可补正文，但不独立证明作者。主聊天本人身份需有一次明确的资料或用户映射证据；否则保留待确认作者候选，不按气泡方向猜实名。
- 分别报告内容覆盖完整性与来源时间精度；独立时间分隔标签不等于每条消息的精确时间。不按导出日期补造消息日期；来源未提供逐条时刻时，时间戳可为空并保留分隔标签上下文，这本身不使内容范围不完整。缺作者证据或缺页时，留在证据中并把归档标为未完成。
- 群聊别名与合并转发里的历史显示名分别保留；只有证据支持时才记录它们的对应关系。
- 若为 history search，只核对并报告查询结果范围；不描述为整段会话完整归档。
- 引用能跳到正确消息；推定与未匹配状态清楚。
- 每页按截图画面自上而下核验。AX diff 的新增条目输出顺序可能不同于消息顺序；优先取完整 AX tree，若工具支持则关闭 diff，否则从截图重建页面顺序，再只反转向上捕获的页批次。临时 element ID 会重编号，不得当作稳定 message ID 或 captureKey。
- 图片导出文件可打开；只按当前窗口实际观察到的保存操作判断媒体状态。合并转发已观察到 Save 导出，但没有发送端原图作比较，因此只能标为 `saved_unverified`，不能称原图已验证。
- 主聊天再捕获一段有重叠的增量；合并转发核对同一固定包的分页重叠并重复导入。旧消息不重收、合法重复不消失。新的手动转发包另建范围，不默认是旧包的实时追加。
- 相同作者、同一时间、相同正文可以是不同消息；字符串匹配不能单独证明出现位置相同。无法靠截图位置、滚动连续性和相邻上下文区分时，保留待核证据并回滚重采，不自动删除候选重复消息。CLI 的歧义拒绝不能代替人工来源核验。
- 全量校验和阅读页搜索、过滤、跳转、图片通过。

在档案的 `SETUP-VALIDATION.md` 记录日期、macOS/微信版本、实际使用模型、UI 工具、权限结果、OCR 结果、范围与逐项结果。机器路径和聊天内容留在本地档案。区分 `synthetic-tests-passed` 与 `live-workflow-validated`；前者不能替代后者。截图/视频不能获取、姓名有歧义、原图无法证明都应记录，不“全部通过”掩盖局限。

仓库中的自动化回归样本只含合成素材；真实验收材料留在本地私有目录，视觉证据如仅存在于会话截图应明确注明而不虚构文件路径。用户在自己机器的首次真实验收成功后，才切换日常 Sol + Luna 分工。微信、macOS、UI 工具或格式发生重要变化后重验受影响步骤。
